`speech-16k.pcm` is `test-audio.raw` from wiseman/py-webrtcvad (MIT; see
`py-webrtcvad-LICENSE.txt`), downloaded from
https://raw.githubusercontent.com/wiseman/py-webrtcvad/master/test-audio.raw.
Mono, signed 16-bit little-endian PCM, 16 kHz. It exercises actual WebRTC
voice decisions; it is not a user's recording or a cloned assistant voice.
